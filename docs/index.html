          Predict a whole CSV

          Upload Kaggle's male_players.csv (or this repo's data/fc24_players.csv). The page applies the same steps as the notebook (FC 24 rows, goalkeepers out, attack–defence gap added, the 15 selected columns) and predicts every player. The file never leaves your device.

          The 13 steps, in short

          1. Data: Kaggle “EA Sports FC 24 complete player dataset” (stefanoleone992), male_players.csv, rows with fifa_version == 24.
          2. Target: first entry of player_positions → FWD (ST, CF, LW, RW, LF, RF) · MID (CM, CDM, CAM, LM, RM) · DEF (CB, LB, RB, LWB, RWB). Goalkeepers dropped.
          3. Cleaning: duplicates, IDs, names, money/club columns and leaking columns (position ratings, club/nation position, overall, potential) dropped; median / mode fill.
          4. New feature: attack_defence_gap = (shooting + dribbling) / 2 − defending.
          5. Encoding + selection: one-hot (get_dummies), then SelectKBest(f_classif, k=15).
          6. Split: 80 / 20, stratify=y, random_state=42.
          7. Model: Random Forest baseline + n_estimators 50 / 100 / 200 + max_depth None / 5 / 10. Best by macro F1 → final model.
          8. Web: train.py exports every tree of the final forest to docs/data/model.js; app.js walks all trees and averages their votes, exactly like scikit-learn's predict_proba.

          Run it yourself

          Notebook: F10_P11_Jatin.ipynb (Colab). Retrain + re-export the web model: python train.py. Streamlit version: streamlit run app.py.
